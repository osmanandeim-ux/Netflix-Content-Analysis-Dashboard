 Netflix Content Analysis Dashboard

 Project Overview
This project analyses Netflix content using Microsoft Excel to explore the distribution of movies and TV shows, content categories, countries, ratings, and content acquisition trends.

 Objectives
- Compare Movies and TV Shows.
- Identify countries contributing the most content.
- Explore the most common genres.
- Analyse content ratings by type.
- Examine content acquisition trends over time.
- Investigate content release years.

 Tools and Techniques
- Microsoft Excel
- Data cleaning
- Power Query
- PivotTables
- Excel formulas
- Charts and dashboard design

 Data Preparation
The dataset was cleaned and prepared for analysis. Duplicate records were removed, and Power Query was used to separate country and genre values for further analysis.

Data limitation: Records with missing country values were excluded from the cleaned dataset. This may affect the results of analyses involving country contributions.

 Key Findings
The dashboard presents visual comparisons of Netflix movies and TV shows, country contributions, genres, content ratings, and trends over time.

Specific findings should be added after verifying the final dashboard figures.

 How to View
Download the Excel workbook from this repository and open it in Microsoft Excel to explore the dashboard.
